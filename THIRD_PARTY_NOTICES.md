- Source release: `edk2-stable202608`
- Original directory: `MdePkg/Include`
- Vendored subset: `third_party/edk2/MdePkg/Include`

- Upstream license text: `third_party/edk2/License.txt`.

The original copyright notices and SPDX identifiers remain intact. These are
type and protocol declarations used to build against UEFI interfaces; the
project does not bundle the complete EDK II firmware distribution.

## External tools and bootloaders

rEFInd, vdiskchain, UEFI Shell, Windows bootloaders, operating-system images,
and proprietary NVIDIA firmware are not distributed in this repository.
Download any required tools from their upstream projects and observe their
respective licenses. The MIT license applies only to this project's original
code and documentation.
